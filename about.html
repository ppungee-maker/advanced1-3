홈 여행 추천 소개

이 서비스는 어떻게 동작하나요?

사용 방법

  1. 여행 추천 메뉴로 이동합니다.
  2. 여행하고 싶은 날짜를 선택합니다.
  3. 추천 받기 버튼을 누르면 AI가 지역·날씨·행사·맛집을 정리해줍니다.

동작 원리

브라우저에서 날짜를 입력하면 JavaScript가 이를 fetch 요청으로 바꿔 /api/recommend(Vercel Serverless Function, Python)로 전송합니다. 서버는 OpenAI API로 여행지를 추천받고, Kakao Local API로 그 지역의 맛집을 검색한 뒤 하나의 JSON 응답으로 합쳐 돌려줍니다. 브라우저는 이 응답을 받아 화면에 카드 형태로 렌더링합니다.

기술 스택

  • HTML / CSS / JavaScript (바닐라)
  • Vercel Serverless Functions (Python)
  • OpenAI API
  • Kakao Local API
  • Vercel 배포
